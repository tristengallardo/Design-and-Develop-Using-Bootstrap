## The challenge

Your challenge is to build out this feature illustration using HTML, Bootstrap and CSS and get it looking as close to the design as possible.

The only assets we provide in this challenge are the image of the person in the app UI and the 3 images of the dog. You need to create everything else using HTML & CSS!

Your users should be able to:

- View the optimal layout for the component depending on their device's screen size

## Reflection
With this assignment, I faced alot of challenges. I struggled and still struggle with understanding Bootstrap and how to implement it into my inline code as compared to making a style sheet (which is more easier for me). The parts of this project that I spent the most time on was the creation of the actual phone model and with having the Simple Booking section actually be next to the phone, surprisingly. To solve these challenges, I spent hours on hours doing research and rereading the Bootstrap documentation given. If I had more time, I definitely would've made more improvement towards actually understanding the concept of Bootstrap.
